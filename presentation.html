實體世界：邊緣硬體設備職責

硬體模組是系統的感官與肌肉，負責在第一線收集物理數據並執行實體澆灌動作。

ESP32 (系統大腦)

做什麼事： 負責邊緣運算 (Edge Computing)。讀取感測器傳來的電壓訊號、執行邏輯判斷，並透過內建 Wi-Fi 模組連接網路。

電容式土壤感測器 (神經網絡)

做什麼事： 捨棄易生鏽的傳統電阻探針，利用「介電常數變化」感測土壤水分，並轉換為類比電壓訊號傳送給大腦。

繼電器與抽水馬達 (執行肌肉)

做什麼事： 接收 ESP32 的 5V 數位高電位指令後，安全驅動大電流抽水馬達，進行物理性的精準給水動作。

數位維度：軟體平台與演算法職責

軟體是賦予硬體靈魂的關鍵。從韌體控制、雲端儲存到資料分析，各司其職。

C++ (底層韌體)

職責： 採用 millis() 異步計時寫法，確保等待連線時「不阻塞」硬體作動；並負責將數據打包成 HTTP 封包上傳。

ThingSpeak (雲端資料庫)

職責： 扮演「時序數據庫」。24 小時接收數據，打上精確時間戳記並永久儲存，提供 API 供外部調用。

HTML/JS (戰情室前端)

職責： 視覺介面。透過 JS 即時撈取 API，將數字渲染成精緻的歷史折線圖與地圖座標燈號。

LINE Messaging API (通報系統)

職責： 警報系統。由 ESP32 底層強制繞過 SSL 憑證驗證，直接將異常 JSON 封包推播至管理員手機。

高階水文資料分析

跳脫簡單的閾值判斷，本專題導入 Python 進行嚴謹的環境工程分析。

SciPy 空間內插演算法

技術原理： 採用「三次空間內插法 (Cubic Interpolation)」，結合微地形梯度，運算並展開為 100x100m 區域的微水文等高線分佈圖，精準定位乾燥熱區。

蒸散斜率與乾燥速率模型

技術原理： 利用 Pandas 撈取歷史時序資料，精準計算出土壤的「乾燥速率 (%/hr)」，協助評估植物的自然蒸散壓力 (ET)，以動態調整澆灌策略。

研究聲明：資料真實性與演算法驗證邊界

為秉持學術嚴謹性，本專題特此說明資料來源界線。本系統中之 ESP32 即時濕度擷取、API 上傳通訊、前端網頁渲染，以及 LINE 主動警報觸發，皆為實體感測器 100% 真實運作之物理數據。

受限於專題初期硬體節點數量限制，Python 後端分析中之 「100x100m 大面積空間水文等高線圖」，係採用部分虛擬觀測站生成資料 (Simulated Data) 作為演算法之概念驗證 (PoC)，旨在證明空間內插邏輯之正確性與未來規模化之潛力。

CHALLENGES & SOLUTIONS

實務困境與工程突破

困境一：感測器該插多深？

❌ 痛點：插太淺易受表面蒸發干擾；插太深則無法反映植物真實吸水狀況。

💡 工程解決方案：鎖定「有效根系帶」

針對草皮類，探針嚴格埋設於深 5~10 公分 處；若為灌木類則深埋至 15~20 公分。此外，安裝時必須將周圍土壤壓實，杜絕「空氣隙」造成的介電常數誤判。

困境二：如何澆出完美弧線且不浪費？

❌ 痛點：傳統水管直射會破壞土壤結構，且水花四濺導致漫流浪費。

💡 工程解決方案：流體拋體計算與微型噴嘴

將噴嘴仰角設定在 30°~45° 以獲得最佳抗風弧線。並改採公式運算：啟動時間(t) = 需水體積(V) / 馬達流量(Q)，搭配微型噴嘴緩慢滲透，達到 100% 根部吸收。

CAMPUS APPLICATION & FUTURE ROADMAP

校方落地應用與系統進化藍圖

這不僅是一份專題，而是為淡江大學永續發展量身打造的解決方案。

校方賦能場景

1. 總務處：智慧校園節能減碳 (ESG)

淡江校區廣大，傳統維護耗費鉅額水費與人力。本系統可協助總務處將花圃升級為自動化管理，落實綠色校園政策。

2. 水環系：微氣候教學與觀測網

長期收集的高解析度數據，可作為師生的教學材料。用於研究校園地表逕流、微地形蒸散量等學術實證分析。

未來系統進化

1. 導入 LoRaWAN 長距離通訊架構

突破 Wi-Fi 覆蓋限制。未來升級將採用低功耗廣域網路 (LoRa)，一個閘道器即可涵蓋整個淡水校園，實現大規模節點聯網。

2. AI 預測模型整合

於雲端導入機器學習 (如 LSTM 時間序列預測)。若 AI 預測即將降雨，系統將強制停止馬達作動，達到最高段的智慧決策。

跨域整合的極致展現

本專題突破了傳統環境工程的框架，將 硬體組裝、韌體開發、雲端建置、Web 視覺化、流體計算以及大數據分析 完美揉合。成功為淡江大學打造出一套具備商業價值、高擴充性的永續水資源管理平台。
